# Tiny Sweepers — glossy 3D covers

Created October 5, 2026 with built-in ImageGen, using the user-supplied Crab Cove thumbnail as a style reference. These are the preferred cover candidates; earlier procedural covers remain available.

| File | Dimensions |
|---|---|
| cover-landscape-v2.png | 1920 × 1080 |
| cover-portrait-v2.png | 800 × 1200 |
| cover-square-v2.png | 800 × 800 |

Generation direction: original cyan and pink round robot vacuum sweepers with expressive screen faces and side brushes collecting colorful rounded cubes on a golden tiled floor; saturated glossy toy-like 3D rendering; chunky yellow TINY and white/cyan SWEEPERS lettering with navy outlines. Full-bleed compositions, title only, no borders, other logos, or watermarks. Each format was separately composed; final exports were resized to submission dimensions.

Portrait and square adaptation prompts required the same characters, palette and exact title, with the title above the robots. Portrait lettering attempts with missing letters were rejected. Accepted artwork was visually checked for the complete TINY SWEEPERS title.

Source image paths, dimensions and byte sizes are recorded in covers-v2.json. Generated originals remain in the ImageGen output directory. The reference was used for visual direction, rather than incorporating its crab characters or game title.

Preview videos begin directly with loaded Level 19, Tung Tung Tung Sahur, gameplay. They contain no cover opening or logo transition. Both are silent, 18 seconds long, with real-time gameplay; recording hides the mouse cursor. Existing SVG files describe the earlier covers, not editable sources for these raster images.
